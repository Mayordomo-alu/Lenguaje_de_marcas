# Quien debe llevar el relative para que la etiqueta este bien colocada?
- Su padre, la tarjeta
# Como arreglarias el overflow para que no tape la etiqueta? 
- Quitando el propio overflow a visible, ajustando la etiqueta en otra posición donde no quede fuera de la etiqueta o sacandola de la tarjeta y poniendo otra posición.

# Visible, hidden, scroll y auto:
- Visible es el default, el texto seguira su curso normal.
- Hidden hará que el texto que se salga del marco no se muestre.
- Scroll añadirá un scroll para desplazar el texto aunque no haga falta.
- Auto lo mismo, pero solo si es necesario.
# visibility:hidden / display:none 
- La visibilidad hace que se escando pero sigue existiendo y deja su hueco vacio.
- El display none hace como si nunca hubiese estado, eliminandolo del bloque para que pueda ocuparlo el siguiente.
